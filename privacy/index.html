隐私政策

更新日期：2026-08-01

我们处理的数据

PS Web Bridge 仅在你主动执行传输时处理所选图片、图片文件名和尺寸、当前 RunningHub 画布项目标识，以及 Photoshop 主动导出的图片。扩展还会在 Chrome 本地保存面板主题、折叠状态和 Photoshop 图层偏好。

用途与传输

这些数据只用于在 rhtv.runninghub.cn、Chrome、本机 PS Web Bridge 和 Adobe Photoshop 之间完成图片传输。RunningHub 图片请求只访问扩展清单声明的 RunningHub 站点；Photoshop 通信只通过 Chrome Native Messaging 访问用户设备上的本地桥接程序。

我们不会做什么

我们不投放广告、不运行分析、不出售数据，也不会把图片或画布内容上传到开发者运营的服务器。除本地界面偏好外，扩展不会长期保存用户内容。

Chrome Web Store Limited Use

The use of information received from Chrome APIs adheres to the Chrome Web Store User Data Policy, including the Limited Use requirements.

English summary

PS Web Bridge handles user-selected images, basic image metadata, the originating RunningHub canvas identifier, Photoshop exports, and local UI preferences only to provide image transfer between RunningHub and Photoshop on the user's device. It contains no ads or analytics, does not sell data, and does not upload image or canvas content to developer-operated servers.

联系与删除

扩展仅保存本地偏好。卸载扩展和本地桥接即可删除其本地数据。如有问题，请通过支持页面提交。
