RunningHub × Photoshop

让无限画布与 Photoshop 双向流动

PS Web Bridge 将你主动选择的图片在 RunningHub 无限画布与本机 Adobe Photoshop 之间传送。Chrome 扩展负责画布交互，本地桥接负责安全调用 Photoshop。

安装 / Install

安装 Chrome 扩展以及适用于 Windows 或 macOS 的本地桥接。

隐私 / Privacy

图片只在用户主动操作时传输，不用于广告、分析或开发者远程存储。
