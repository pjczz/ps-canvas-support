故障排查

面板没有出现

  • 确认网址是 https://rhtv.runninghub.cn/projects/canvas/<项目ID>，而不是项目首页或海外站。
  • 在 Chrome 扩展页面确认 PS Web Bridge 已启用，然后刷新画布。

Photoshop 没反应

  • 先打开 Photoshop 2021 或更新版本。
  • 确认已安装本机桥接；仅安装 Chrome 扩展是不够的。
  • Windows 用户运行安装包中的“一键诊断”，macOS 用户重新运行安装器的诊断步骤。

提交问题

请在 GitHub Issues 提交系统版本、Chrome 版本、Photoshop 版本、扩展版本、完整报错截图和诊断报告。诊断报告可能包含本机路径，请在公开提交前遮盖个人信息。

English

If the panel is missing, confirm that you are on a concrete rhtv.runninghub.cn/projects/canvas/<id> page and reload it. If Photoshop does not respond, install the matching local companion and open Photoshop before retrying. Report reproducible issues through GitHub Issues.
