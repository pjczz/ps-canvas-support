安装本地桥接

Chrome 商店只安装浏览器扩展。要连接 Photoshop，还需要安装与你的系统匹配的本地桥接。

Windows 10/11 x64

  1. 从最新发布页下载 Windows ZIP。
  2. 完整解压后双击“安装 PS Web Bridge.bat”。
  3. 选择 Photoshop 2021 或更新版本的 Photoshop.exe。
  4. 回到 Chrome，刷新具体 RunningHub 无限画布。

macOS 14 或更新版本

  1. 从最新发布页下载已签名并公证的 macOS 安装包。
  2. 运行 PKG 并按系统提示完成权限设置。
  3. 重新打开 Chrome 与 Photoshop，再刷新具体无限画布。

English

Install the Chrome Web Store extension first, then install the signed companion package for Windows or macOS from the latest release page. Open a concrete RunningHub canvas and reload it once. The PS Web Bridge panel should appear at the bottom-right.
