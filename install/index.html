安装本地桥接

Chrome 商店版本仍在审核期间，可使用独立安装包中的“加载已解压的扩展程序”方式。独立版使用固定的本地开发 ID，不依赖 Chrome 商店 Item ID 或审核状态。无论采用哪种扩展安装方式，要连接 Photoshop 都需要安装与你的系统匹配的本地桥接。

Windows 10/11 x64

  1. 从最新发布页下载 Windows ZIP。
  2. 完整解压后双击“安装 PS Web Bridge.bat”。
  3. 选择 Photoshop 2021 或更新版本的 Photoshop.exe。
  4. 审核期间按安装助手提示，在 chrome://extensions/ 开启开发者模式并加载安装包提供的扩展目录。
  5. 回到 Chrome，刷新具体 RunningHub 无限画布。

macOS 14 或更新版本

  1. 从最新发布页下载已签名并公证的 macOS 安装包。
  2. 运行 PKG 并按系统提示完成权限设置。
  3. 重新打开 Chrome 与 Photoshop，再刷新具体无限画布。

English

While the Chrome Web Store listing is under review, use the unpacked extension included with the standalone package. Its stable local development ID does not depend on a Web Store Item ID or review status. Install the Windows or macOS companion package as well, then open a concrete RunningHub canvas and reload it once. The PS Web Bridge panel should appear at the bottom-right.
